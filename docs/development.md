# 빵마스터 제품 계획

이 문서는 현재 구현 상태와 다음 개발 순서를 관리합니다. 기능 우선순위는 서비스 사용 흐름을 막는 위험과 선행 관계를 기준으로 정하며, P0는 데모를 보여주고 핵심 연습을 완료할 수 있어야 하는 범위, P0.1은 매장 운영 준비, P1은 평가·개인 학습 이력, P2는 확장 기능입니다.

## 현재 구현 상태

| 영역 | 상태 | 구현 내용과 한계 |
| --- | --- | --- |
| 공개 체험 | 구현 | 상품 도감, POS 분류 퀴즈, 유사 상품명 양방향 퀴즈, 배달 기본·심화, POS 결제 연습, 재고 입력 연습. 실제 POS·재고 시스템과 연결되지 않음 |
| 계정·매장 | 1차 구현 | 이메일 가입·로그인, 매장 생성·참여 신청, 관리자 승인, 관리자·근무자 권한 분리. 이메일 소유 인증·비밀번호 재설정은 미구현 |
| 관리자 메뉴 | 구현 | 카테고리·메뉴·POS 위치 관리, CSV·엑셀 업로드, POS 이미지 인식 보조, 상품 링크, 사진 업로드 |
| 퀴즈 관리 | 구현 | 메뉴명 기반 추천, 관리자의 그룹 생성·수정·승인·중지. 사진 외형 자동 비교 추천은 미구현 |
| 학습 현황 | 구현 | 본인 풀이 이력·오답 노트·모드별 누적 정답률, 관리자 기본 연습 통계 |
| 사용자별 연습 저장 | 구현 | 매장에 연결된 계정에서 시작한 연습을 사용자·매장·모드 기준으로 저장하고 다른 매장 계정의 접근을 막음. 비회원 체험과 사용자별 연습 기록은 별도 경로 |
| 평가·시험 | 구현 | 승인된 근무자의 10문항 혼합 평가(5개 영역별 2문항), 이어 풀기, 제출 결과 저장, 관리자 요약 조회 |
| 레벨·랭킹·보상 | 미구현 | 현재 진행 현황 API의 간단 레벨은 누적 정답 수 임시 구간이며 게임 레벨·공식 랭킹이 아님. 급여 조정이나 보상 연동 없음 |

현재 데이터 모델과 화면 정의는 [계정·매장 문서](accounts.md), [퀴즈 관리 문서](quiz-management.md), [ERD](erd.md)를 참고합니다.

| P1 | 평가 모드 | 구현. 연습과 분리된 혼합 평가, 제출 결과의 근무자·점주 조회 |

| P2 | 레벨·매장 랭킹 | 공개 범위·산정 기간·동점 처리·부정 방지·참여 동의 결정 후 집계. 점수만으로 급여나 근무를 자동 결정하지 않음 |
| P2 | 운영 고도화 | 보류 상품 검수, 계정 인증·비밀번호 재설정, 감사 가능한 평가 정책, 매장별 운영 도구 |

## 학습 기록과 평가 운영

- **내 계정 → 근무 매장 → 내 학습 현황**에서 모드별 누적 정답률과 채점한 풀이 기록을 확인합니다. 오답 노트의 새 퀴즈 기록은 당시 문항으로 다시 풀 수 있습니다. 이전에 보기 스냅샷이 저장되지 않은 기록은 정답 상품을 표시합니다. POS·배달 심화는 주문의 상품별 수량 차이를 표시합니다.
- **업무 평가**는 승인된 근무자에게 제공됩니다. 카테고리 분류, 사진 보고 상품명 선택, 이름 보고 사진 선택, 배달 상품 찾기, POS 메뉴 찾기에서 각 2문항씩 총 10문항입니다. 사진이 등록된 상품 4개 이상과 2개 이상의 카테고리, 양방향 유사 상품 퀴즈에 필요한 활성 그룹·사진 상품이 있어야 시작할 수 있습니다.
- 서버는 평가 문항과 답안을 별도로 저장합니다. 근무자는 진행 중인 평가를 이어 풀거나 답을 수정할 수 있습니다. 모든 답을 제출하면 100점 만점으로 채점하며, 총점과 영역별 정답 수가 확정됩니다. 이전 정책으로 완료된 기록은 유지됩니다.
- 관리자는 **근무자 학습 현황 → 평가 결과 보기**에서 동일 매장의 승인된 근무자가 제출한 평가의 총점·영역별 결과·제출 시각을 확인합니다. 점수는 일상 연습 통계 및 급여·인사 결정과 연결되지 않습니다.
- 초기 구현에는 평가 시간 제한과 재응시 횟수 제한이 없습니다. 계정·매장별로 진행 중인 평가를 하나 유지하며, 제출 후 응시할 때 새 평가를 생성합니다. 제출 결과는 최근순으로 조회합니다.

학습 기록의 저장 범위, 오답 복습 조건, 권한별 API와 제한은 [학습 기록·오답 노트·평가 상세](learning-records-and-assessment.md)를 참고하세요.
