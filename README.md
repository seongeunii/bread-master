# 빵마스터 · Bread Master

베이커리 신입 근무자를 위한 상품 학습 및 POS 탐색 연습 웹 앱.
현재는 **로컬 개발용 데모**입니다. 공식 사이트에서 수집한 브레드 상품과 개발용 예시 데이터를 구분합니다. 공식 상품의 가격은 미등록이며 분류는 사이트 기준입니다. 실제 POS 및 결제 시스템과 연결하지 않습니다.

## 구성

- `frontend/`: React + TypeScript + Vite + Tailwind CSS
- `backend/app/main.py`: 상품 조회, 문제 출제, 서버 채점 API
- `backend/app/learning.py`: 단계별 출제·점수·상황별 피드백
- `frontend/src/features/learning/`: 단계 선택·라운드·점수 화면
- `frontend/src/features/inventory/`: 재고 수정·등록·카테고리 저장 화면
- `backend/app/inventory.py`: 연습 재고 생성·복원·저장 API
- `backend/app/db.py`: SQLite 연결, 테이블 생성, 예시 데이터
- `backend/tests/`: 필터·채점·중복 답안·유효성 검증
- `.vscode/`: Python 환경, 추천 확장, 실행 작업

상단 메뉴는 상품 도감 / 상품명 퀴즈 / 재고 등록입니다. 상품 도감(검색·카테고리·상세)과 네 단계 학습, 재고 입력 연습을 제공합니다.

1. 카테고리: 일러스트를 보고 카테고리 선택
2. 상품명: 사진 → 이름 또는 이름 → 사진을 선택하여 유사 이름 그룹의 2~3개 상품을 구분
3. 배달: 주문 이름만 보고 4개의 일러스트 중 선택 (보기에는 이름 숨김)
4. POS: 일러스트를 보고 카테고리·페이지를 탐색해 상품 등록

각 단계는 독립적으로 선택하며 라운드당 중복 없는 5문제, 정답당 20점, 100점 만점입니다.
서버가 점수와 상황별 피드백을 반환합니다. 라운드 점수는 화면에 합산하며 새로고침·단계 변경 시 초기화됩니다.
오답이면 정답을 표시하고, 최종 결과에는 점수·정답률·헷갈린 상품을 보여줍니다.
유사 이름 그룹은 `products.name_group`에 지정합니다. 실제 데이터 도입 시 직접 검수해야 합니다.
기존 SQLite 데이터는 삭제하지 않고 필요한 컬럼을 추가합니다.

## 배달 심화 연습

상품명 퀴즈 → 3단계 배달 연습 → 심화에서 주문서대로 포장합니다. 2~4종의 상품을 주문하며 상품별 수량은 1개 80%, 2개 16%, 3개 3%, 4개 1%입니다. 후보 사진은 최대 15개(현재 예시 상품 12개)이며 상품명은 숨깁니다. 사진 한 번 탭에 1개를 담고, 장바구니에서 1개씩 빼거나 비울 수 있습니다.

포장 완료 시 서버가 상품과 수량의 정확한 일치를 채점합니다. 주문당 정답 20점이며 자유롭게 다음 주문을 연습합니다. 틀리면 부족·초과 상품과 수량을 보여줍니다. 첫 제출 결과를 저장해 반복 제출로 점수가 바뀌지 않습니다. 심화 점수는 현재 화면 기준으로 모드 변경·새로고침 시 초기화됩니다. 기본 배달 연습은 기존 5문제 방식입니다.

## 재고 등록 연습

출제·정답·점수 없이 POS 형태로 직접 조작합니다. 예시 초기 재고는 상품당 3개입니다. 상품 선택 → 총수량 수정(3개에 4개 추가 시 7 입력) → 수량 등록 → 카테고리 저장 순서입니다. 수정하지 않은 상품은 그대로 유지하며, 미등록 입력이나 저장 대기 변경이 있으면 카테고리 이동을 막습니다. 0~9999 사이 정수만 저장할 수 있습니다.

연습별 재고는 별도 SQLite 테이블에 저장합니다. 브라우저 탭의 sessionStorage에 연습 ID를 보관해 새로고침 시 저장된 수량을 복원합니다. 저장하지 않은 변경은 복원되지 않습니다. 실제 상품 정보나 재고에는 영향을 주지 않습니다.

## 실행

Node.js 22.12 이상 또는 24 LTS 권장. Python은 현재 설치된 3.9에서 검증했으며 신규 환경은 3.12 이상 권장.

터미널 1:

```sh
cd backend
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

터미널 2:

```sh
cd frontend
npm ci
npm run dev
```

웹: http://localhost:5173 · API 문서: http://127.0.0.1:8000/docs
프론트엔드의 `/api` 요청은 Vite가 백엔드로 전달합니다.
SQLite는 `backend/bread.db`에 생성되며 Git에서 제외됩니다.

## 공식 브레드 상품 데이터

2026-10-11 공식 브레드 공개 목록에서 이름·사진 URL·출처 176개를 수집했습니다.
사이트 하위 분류를 사용하며 POS 실제 분류가 아닙니다. 가격은 수집하지 않고 미등록으로 표시합니다.
상품 이미지의 권리는 원 출처에 있으며 이 등록은 재사용 허락을 의미하지 않습니다.
이미지는 외부 URL을 참조하므로 원본 변경 또는 삭제 시 표시되지 않을 수 있습니다.

수집: `backend/.venv/bin/python backend/scripts/collect_paris.py`
등록: `backend/.venv/bin/python backend/scripts/import_paris.py`
등록은 기존 DB를 백업하고 출처 URL로 중복을 방지합니다. 예시 상품 및 기존 기록을 삭제하지 않습니다.
공식 상품이 있으면 도감과 출제는 공식 상품을 우선 사용합니다.
유사 상품명 퀴즈는 검수한 `name_group` 설정이 필요하며, 수집만으로 유사 그룹을 임의 생성하지 않습니다.

## 사진 기준 POS 연습

POS와 재고 연습은 공통 PosTerminal 화면을 사용합니다. PC에서는 상단 두 줄 카테고리 / 왼쪽 등록 내역 / 오른쪽 5×5 상품 칸 / 하단 조작 영역으로 표시합니다. 모바일 세로는 상품 선택을 먼저 표시합니다. 재고는 숫자 키패드로 총수량을 입력하고 등록 및 카테고리 저장을 완료합니다.

사이트 분류와 POS 분류는 독립적입니다. backend/app/pos.py에 사진에서 확인한 카테고리와 칸 위치를 관리합니다. 같은 상품명이 여러 페이지에 존재하면 임의로 선택하지 않습니다. 미확인 상품·칸·케이크 및 샌드위치 사진은 현재 공식 브레드 데이터와 연결하지 않아 비워 둡니다. POS 문제는 배치에 연결된 상품만 출제합니다. 가격은 아직 미등록입니다.

기존 재고 연습은 생성 당시의 상품 목록을 유지합니다. 사진 배치로 시작하려면 '새 재고 연습'을 사용합니다. 기존 도감 분류와 저장된 답안은 유지합니다.

## 도감과 POS 결제 연습

상품 도감은 POS 연습과 같은 카테고리·5×5 상품 칸으로 표시하고 왼쪽에서 선택 상품 정보를 확인합니다. 검색 및 POS 미배치 상품 탭으로 수집한 모든 상품을 계속 조회할 수 있습니다. 미배치와 검색 결과의 칸 순서는 도감 탐색용입니다.

POS 연습은 1~3종의 상품 사진과 수량을 제시합니다. 상품을 누를 때마다 등록 수량이 1개씩 증가하고 왼쪽 목록의 ×로 해당 상품 행 전체를 삭제합니다. 수량 입력 및 키패드 없이 오른쪽 하단 결제 버튼으로 전체 상품과 수량을 서버에서 채점합니다. 5주문, 정답당 20점, 총 100점이며 실제 결제는 없습니다. 재고 연습은 기존 수량 입력 및 키패드를 유지합니다.

## 사용자 제공 POS 데이터 보정 (2026-10-12)

backend/data/pos-layout.json에 7개 분류, 78개 메뉴의 표시 이름·가격·칸 위치를 저장합니다. 5개 오타·축약명은 사용자가 확인한 이름으로 수정했습니다. 단과자 특수 메뉴는 묶음빵(8,000원), 빵류(직접 단가 입력), 종이쇼핑백(100원)입니다. 일반 상품 가격은 사용자 제공 값이며 사이트 상품 가격을 변경하지 않습니다.

공식 상품명과 POS 별칭을 분리합니다. 같은 사이트 이름이 여러 페이지에 존재하거나 공식 사진을 찾지 못하면 다른 빵 사진을 임의로 넣지 않고 '사진 확인 필요'로 표시합니다. 묶음·반쪽 제품의 사이트 사진은 참고 이미지입니다. 사진 미확인 메뉴는 사진 퀴즈에서 출제하지 않습니다.

빵류는 POS 연습에서 직접 가격을 입력하고 등록 목록에서 단가만 수정할 수 있습니다. 현재 채점은 사진 주문의 상품·수량 일치 기준입니다. 재고 연습에서는 직접 단가 메뉴인 빵류를 제외합니다. 기존 재고 세션은 이전 배치를 유지하므로 새 배치 사용 시 새 재고 연습을 시작합니다.

## 학습 분류 통일

모든 신규 퀴즈(카테고리·상품명·사진 선택·배달)와 심화 배달은 사용자 제공 POS 분류 및 이름을 사용합니다. 상품 API도 POS 분류를 반환하며, 분류를 확정하지 못한 상품은 POS 미분류로 표시하고 출제에서 제외합니다. 사이트 분류는 원본 수집 데이터에만 남겨 두며 학습 화면이나 정답 안내에서는 사용하지 않습니다.
